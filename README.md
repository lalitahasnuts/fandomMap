# 🗺️ Карта фандома (Genshin Impact)

Веб-приложение для исследования вселенной Genshin Impact: связи между персонажами, таймлайн событий по регионам, теории фанатов и быстрый поиск по тропам.

> Учебный проект на React. Делается как пет-проект, чтобы разобраться с роутингом, состоянием, графами и компонентным подходом.

---

## ✨ Что уже реализовано

- **Хедер с навигацией** на всех страницах (реализован через общий `Layout` и `<Outlet />`).
  - Активная вкладка подсвечивается через `NavLink`.
  - Hover-эффекты в едином стиле с карточками: подсветка, акцентная обводка, лёгкий подъём.
  - Кнопка поиска прижата к правому краю хедера.

- **Главная страница**:
  - Hero-блок с заголовком и подписью.
  - Три карточки-раздела: «Карта связей», «Таймлайн», «Теории». Клик ведёт на соответствующую страницу (`useNavigate`).
  - Секция «Последние теории» с тремя карточками из данных.

- **Страница «Теории»**:
  - Полноценная сетка карточек (`theory-grid`).
  - Поиск по заголовку и тегам.
  - Ползунок «Спойлеры до: X» с живым значением (1, 2, 3).
  - Компонент `TheoryCard` скрывает аргументы за спойлер-заглушкой, если уровень спойлера превышает допустимый.

- **Страница «Таймлайн»**:
  - Разбивка событий по **регионам** (Мондштадт, Ли Юэ, Инадзума и т.д.), а не по сезонам.
  - Переключение между регионами через табы (`useState`).
  - Спойлеры 3-го уровня скрыты и раскрываются по клику (как в прототипе).
  - Формат данных: `region`, `title`, `description`, `spoiler`, `tags`.

- **Страница «Карта связей»**:
  - Интерактивный граф на [React Flow](https://reactflow.dev/).
  - Загрузка узлов и связей из `characters.json`.
  - Узлы можно перетаскивать, есть зум и кнопки управления.
  - Тёмная тема графа (`colorMode="dark"`).

- **Тёмная тема** — цвета заданы через CSS-переменные в `:root`. Легко перекрашивается правкой одного блока.

- **Данные в JSON** — `src/data/theories.json`, `src/data/events.json`, `src/data/characters.json`.

- **Скругления карточек** настраиваются одной переменной `--radius-md`.

## 🛠️ Стек

| Технология | Зачем |
|---|---|
| React 18+ | UI |
| Vite | Сборка и dev-сервер |
| React Router | Навигация между страницами |
| [React Flow](https://reactflow.dev/) (`@xyflow/react`) | Интерактивный граф связей |
| CSS (переменные + обычные стили) | Оформление, тёмная тема |
| JSON | Хранение данных |

Никаких backend, Redux, TypeScript пока нет — сознательно, чтобы сначала разобраться с базой.

## 📁 Структура проекта

```
src/
  components/
    Header.jsx          # Верхняя навигация
    Layout.jsx          # Обёртка: Header + Outlet
    FeatureCard.jsx     # Карточка-раздел на главной
    TheoryCard.jsx      # Карточка теории
    EventItem.jsx       # Одно событие таймлайна
  pages/
    Home.jsx            # Главная
    Characters.jsx      # Карта связей (React Flow)
    Timeline.jsx        # Таймлайн по регионам
    Theories.jsx        # Теории с поиском и спойлерами
  data/
    theories.json       # Теории по Genshin
    events.json         # События по регионам
    characters.json     # Узлы и связи для графа
  App.jsx               # Роутинг
  main.jsx              # Точка входа, BrowserRouter, импорт стилей
  index.css             # Все стили и CSS-переменные
```

## 🚀 Как запустить

Требуется Node.js 18+.

```bash
# 1. Клонировать
git clone https://github.com/lalitahasnuts/fandomMap
cd fandomMap

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npm run dev
```

Откройте http://localhost:5173.

**Другие скрипты:**

```bash
npm run build      # прод-сборка в dist/
npm run preview    # локально посмотреть прод-сборку
```

## 📊 Формат данных

**Теория** (`src/data/theories.json`):

```json
{
  "id": 1,
  "title": "Снейп любил Лили",
  "spoiler": 2,
  "arguments": ["Патронус — лань", "Всегда защищал Гарри"],
  "tags": ["#разоблачение", "#жертва"]
}
```

**Событие таймлайна** (`src/data/events.json`):

```json
{
  "id": 1,
  "region": "Мондштадт",
  "title": "Пробуждение Двалина",
  "description": "Начало сюжета, знакомство с городом свободы.",
  "spoiler": 1,
  "tags": ["#завязка", "#дракон"]
}
```

**Персонаж и связь** (`src/data/characters.json`):

```json
{
  "nodes": [
    { "id": "diluc", "position": { "x": 100, "y": 100 }, "data": { "label": "Дилюк" } }
  ],
  "edges": [
    { "id": "e1", "source": "diluc", "target": "kaeya", "label": "братья", "type": "conflict" }
  ]
}
```
