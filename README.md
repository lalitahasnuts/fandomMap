# 🗺️ Карта фандома

Веб-приложение для исследования сложных вымышленных вселенных: связи между персонажами, таймлайн событий по сезонам, теории фанатов и быстрый поиск по тропам.

> Учебный проект на React. Делается как пет-проект, чтобы разобраться с роутингом, состоянием и компонентным подходом.

---

## ✨ Что уже реализовано

- **Хедер с навигацией** на всех страницах (реализован через общий `Layout` и `<Outlet />`).
  - Активная вкладка подсвечивается через `NavLink`.
  - Hover-эффекты в едином стиле с карточками: подсветка, акцентная обводка, лёгкий подъём.
  - Кнопка поиска прижата к правому краю хедера.

- **Главная страница**:
  - Hero-блок с заголовком и подписью.
  - Три карточки-раздела: «Карта связей», «Таймлайн», «Теории». Клик ведёт на соответствующую страницу (`useNavigate`).
  - Секция «Последние теории» с тремя карточками из данных.

- **Карточка теории** (`TheoryCard`) — переиспользуемый компонент:
  - Заголовок и бейдж уровня спойлера.
  - Список аргументов **или** спойлер-заглушка, если уровень спойлера выше разрешённого (`maxSpoiler`).
  - Теги в виде «пилюль».

- **Карточка-раздел** (`FeatureCard`) — переиспользуемый компонент для навигации по разделам.

- **Тёмная тема** — цвета заданы через CSS-переменные в `:root`. Легко перекрашивается правкой одного блока.

- **Данные в JSON** — `src/data/theories.json`, импортируются как `import theories from "../data/theories.json"`.

- **Скругления карточек** настраиваются одной переменной `--radius-md`.

## 🚧 В планах

- [ ] **Карта связей** — интерактивный граф персонажей (союз / конфликт / романтика). Планируется на [React Flow](https://reactflow.dev/).
- [ ] **Таймлайн** — события по сезонам с раскрытием спойлеров по клику.
- [ ] **Страница «Теории»** — полноценная сетка с поиском и ползунком уровня спойлеров.
- [ ] **Поиск** по всему приложению (персонажи, события, теории, теги).
- [ ] **Сохранение прогресса** — текущий уровень спойлеров в `localStorage`.
- [ ] **Адаптив** под мобильные экраны.
- [ ] **Тёмная / светлая темы** — переключатель вручную.

## 🛠️ Стек

| Технология | Зачем |
|---|---|
| [React 18+] | UI |
| [Vite] | Сборка и dev-сервер |
| [React Router] | Навигация между страницами |
| CSS (переменные + обычные стили) | Оформление, тёмная тема |
| JSON | Хранение данных на старте |

Никаких backend, Redux, TypeScript пока нет — сознательно, чтобы сначала разобраться с базой.

## 📁 Структура проекта

```
src/
  components/
    Header.jsx          # Верхняя навигация
    Layout.jsx          # Обёртка: Header + Outlet
    FeatureCard.jsx     # Карточка-раздел на главной
    TheoryCard.jsx      # Карточка теории
  pages/
    Home.jsx            # Главная
    Characters.jsx      # Карта связей (заглушка)
    Timeline.jsx        # Таймлайн (заглушка)
    Theories.jsx        # Теории (заглушка)
  data/
    theories.json       # Данные теорий
  App.jsx               # Роутинг
  main.jsx              # Точка входа, BrowserRouter, импорт стилей
  index.css             # Все стили и CSS-переменные
```

## 🚀 Как запустить

Требуется Node.js 18+.

```bash
# 1. Клонировать
git clone https://github.com/ваш-логин/ваш-репозиторий.git
cd ваш-репозиторий

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npm run dev
```

Откройте http://localhost:5173.

**Другие скрипты:**

```bash
npm run build      # прод-сборка в dist/
npm run preview    # локально посмотреть прод-сборку
```
